## Featured Projects

### 🧬 [RNA-seq Nextflow Pipeline](https://github.com/jydubbs/rna-seq-pipeline-nextflow)
End-to-end RNA-seq workflow using Nextflow, HISAT2, featureCounts and DESeq2 on a Slurm HPC cluster.

### 🧬 [Directed Evolution Web Portal](https://github.com/jydubbs/Direct-Evolution-Monitoring-Web-Portal)
Developed the experimental staging pipeline for validating plasmid sequences, identifying ORFs and matching them to UniProt reference proteins.

### 🤖 [AI-assisted Multimodel Target Prioritisation](https://github.com/jydubbs/ai-multimodal-target-prioritisation)
An LLM-powered assistant platform for integrating heterogenous biological datasets such as RNA-seq, proteomics, GWAS, and spatial transcriptomics, to prioritise disease gene, pathways, and therapeutic targets.
**This project is under active development as a long-term research and software engineering project.**

## Built for Fun

Small tools I built for myself to enforce better daily habits. Feel free to try them out for yourself!

### 🐾 [Pocket Pet](https://github.com/jydubbs/desktop-pocket-pet)
A desktop pet for Mac and Windows that hatches, grows and evolves as you tick off tiny daily habits, with 16 species, rare shinies, and a café where grown-up pets hang out. Built with Electron, with automated Mac and Windows builds through GitHub Actions.

### 📓 [Gratitude Ledger](https://github.com/jydubbs/gratitude-ledger)
A simple gratitude journal that lives in the Mac menu bar, for jotting down daily emotions and gratitudes.

### 🧠 [Morning Whetstone](https://brain-whetstone.fun)
A daily 10-minute thinking question to keep reasoning sharp in the AI era, on the web and by email at 7am. Built and deployed on Cloudflare Workers with a D1 database, scheduled jobs and Resend for email, on a custom domain with SPF/DKIM/DMARC.
